Risser Rewards V50.1

Adds:
- Quick Edit shortcuts at the top of Settings for:
  Edit Jobs / Responsibilities, Edit Growth Missions, Edit Rewards.
- Parent can add custom Growth Missions.
- Parent can edit Growth Mission name, icon, description, XP and schedule.
- Parent can remove built-in or custom kid-facing Growth Missions.
- Removal is non-destructive: the mission is hidden but historical completions, XP and ledger history remain.
- Hidden missions can be restored.
- Custom missions persist in the existing challenges array and use the same approval/history engine.

No Firebase rules changes expected.
